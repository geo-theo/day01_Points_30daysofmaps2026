## Cell 03: Restaurant rating and distance OLS

Attach `data/observable/final/data/restaurants_paris.geojson` as `restaurants_paris.geojson`, then paste [03_restaurant_rating_ols.js](03_restaurant_rating_ols.js) into one Observable Notebooks 2.0 JavaScript or TypeScript cell. The cell imports Observable Inputs, Observable Plot, htl, and jStat from npm.

The radio selector switches between all restaurants and those no more than 1,500 metres from the tower, with the 1.5 km scope selected by default. An optional review filter defaults to a minimum of 3 `reviews_count_in_default_language` when enabled; it keeps restaurants at or above the entered nonnegative integer and excludes records with missing counts. This filter affects both table and chart. For each selection, the table shows the distance coefficient in rating points per kilometre, its conventional OLS standard error, t statistic and two-sided p value, plus sample size, excluded records and R². Coefficients carry `***` for p < 0.01, `**` for p < 0.05, and `*` for p < 0.10, using the unrounded p value. The unadjusted model uses rows with finite rating and nonnegative finite distance. The adjusted model also requires price and cuisine, so it can use a smaller sample.

The adjusted model treats price as an ordered numeric variable (€ = 1, €€-€€€ = 2, €€€€ = 3), uses categorical cuisine indicators, and controls for `awards` (1 for nonblank text, 0 for blank or null). The first comma-separated cuisine is grouped as French, European, Japanese, or Other cuisines; missing cuisines are excluded. The most common group in the adjusted sample is the reference. On the supplied dataset, the available first `top_tags` in that sample duplicate the price categories, so adding all those tag indicators alongside price would make the model collinear; they are omitted. These are associations, and the reported uncertainty assumes the usual conventional OLS model. Award entries may themselves be related to reviews or ratings, which affects how the adjusted distance association should be interpreted.

Below the table, the **Plot variables** selector switches chart modes. The distance axis is linear by default, with an optional log scale; log axes display only positive distances, but fits still use all valid nonnegative distances in their sample. In **Linear Regression Model**, dark grey points and the black dotted baseline use the unadjusted sample; the cyan curve is the controlled model with price, award status, and cuisine indicators held at their respective adjusted-sample means. Its categorical means represent sample proportions, so the curve is an average fitted relationship rather than a particular restaurant's prediction. Curves cover each model's displayed distance range, with conventional 95% confidence bands for mean fitted rating, not prediction intervals. Lines are fitted in kilometres even when the log-scaled axis makes them appear curved. The adjusted and unadjusted models can use different samples.

The **Price Level**, **Cuisine**, and **Awarded** options show separate unadjusted within-group regressions and 95% confidence bands alongside a black dotted pooled baseline. Legend checkboxes hide or show each group's points and line; the baseline is refitted using only visible groups, and it too can be hidden. Visibility choices are remembered separately for each chart mode. The labels on lines are distance coefficients per kilometre, with the same significance stars as the table. The table continues to show the two overall models and does not change when only chart or legend selections change. Price and cuisine plots exclude records without a recognized group, while Awarded treats blank awards as no recorded award. Cuisine uses the same four first-listed cuisine groups as the adjusted model. Each group line needs at least three observations and variation in distance; group points remain visible if a line cannot be fitted. A grouped plot's sample can differ from the table's sample, and the plot displays its count. Grouping by a variable can expose differing trends, but differing or reversed group slopes alone do not establish causation or prove a Simpson's paradox.

## Cell 04: Spearman's rank correlation

Attach `data/observable/final/data/restaurants_paris.geojson` as `restaurants_paris.geojson`, then paste [04_spearman_correlation.js](04_spearman_correlation.js) into one Observable Notebooks 2.0 JavaScript or TypeScript cell. It imports D3, htl, and jStat from npm. The bootstrap runs in a browser worker and can take some time.

The primary analysis includes restaurants within 1,500 metres, including the endpoint, with finite `rating` and finite nonnegative `distance_from_eiffeltower_m`. The supplied Paris GeoJSON also contains restaurants farther away, so the cell applies this distance limit explicitly. Two secondary analyses use non-overlapping groups: 0 to less than 500 metres, and 500 through 1,500 metres. A D3 results table reports n, Spearman's rho, a one-sided p-value for the positive alternative, and a two-sided 95% confidence interval for each sample. These tests do not directly test whether the associations differ between groups. Ranks are recomputed with average ranks for ties. The p-value uses the usual large-sample t approximation, which may be unreliable for small samples; the interval uses 2,000 paired restaurant-level percentile bootstrap resamples with fixed seeds. It is unavailable if any resample has constant values. Neither the test nor the restaurant-level bootstrap accounts for spatial dependence between nearby restaurants. The analysis measures association, not causation.

## Cell 05: Jonckheere–Terpstra ordered trend

Attach `data/observable/final/data/restaurants_paris.geojson` as `restaurants_paris.geojson`, then paste [05_jonckheere_terpstra.js](05_jonckheere_terpstra.js) into one Observable Notebooks 2.0 JavaScript or TypeScript cell. It uses htl; the three permutation tests run in a browser worker. The named `cell05Data` and `cell05Results` objects hold the prepared observations and results, including simulated distributions, for reuse in the notebook.

The primary test uses the six existing distance-band labels and finite `rating` values within 1,500 m. Exploratory tests use the first two bands (0 to less than 500 m) and the four bands from 500 m through 1,500 m. Unrecognized labels are excluded; unrecognized or inconsistent labels are recorded in `cell05Data.mismatches` rather than replaced. All three one-sided tests use 9,999 fixed-seed permutations, count tied cross-band comparisons as half, and report the corrected permutation p-value, normalized favorable-comparison proportion P, and directional dominance D = 2P − 1. The result depends on exchangeability under permutation, which spatial dependence can undermine; it does not establish causation. A nonsignificant exploratory test does not prove the trend disappears, and the tests do not directly compare the trends.

## Cell 07: Generalized additive model

Attach `data/observable/final/data/restaurants_paris.geojson` as `restaurants_paris.geojson`, then paste [07_generalized_additive_model.js](07_generalized_additive_model.js) into one Observable Notebooks 2.0 JavaScript or TypeScript cell. It imports Observable Plot, Observable Inputs, and htl. The source's numbered sections organize the data, model, predictions, diagnostics, and interpretation within that single cell. Named values including `gamData`, `gamUnadjusted`, `gamAdjusted`, `gamPredictions`, and `gamDerivatives` are available to later cells.

The primary sample contains finite `rating` and nonnegative finite distance values within 1,500 m. The supplied data yield 1,070 observations, ranging from approximately 166 to 1,499 m, including nine within 250 m. The Gaussian identity-link GAM uses a cubic B-spline basis with a second-difference penalty, selects smoothing by generalized cross-validation, and compares five-fold prediction error to a linear regression. Confidence bands and paired contrasts use 300 fixed-seed restaurant bootstrap resamples with smoothing reselected each time. `cell07BootstrapIterations` can be increased, at the cost of more runtime. Confidence intervals describe the expected mean and are pointwise, not individual prediction intervals or simultaneous bands. They assume independent restaurants and may underestimate uncertainty when ratings are spatially dependent.

The adjusted model uses the same sample and adds log review count, price, first-listed cuisine, and language; rare categories are pooled, missing categories are retained as Unknown, and missing log review counts receive median imputation and a missingness indicator. Its distance curve averages predictions over the original sample's controls. The cell also reports basis and smoothing sensitivity, leave-one-out checks for the closest restaurants, a five-review minimum sensitivity, and residual plots. These are observational associations; the Gaussian approximation does not enforce the ratings' 1–5 bounds.

## Cell 09: Center-anchored permutation analysis

Attach `data/observable/final/data/restaurants_paris.geojson` as `restaurants_paris.geojson`. The five numbered sections in [09_center_anchored_permutation.js](09_center_anchored_permutation.js) are separate Observable Notebooks 2.0 JavaScript or TypeScript cells: paste them in order. The first prepares the data and configuration, the second defines the permutation functions, the third runs the analysis, and the last two display the plot and table. The narrative is maintained separately in a notebook Markdown cell. Named values include `permutationData`, `cell09Result`, and `cell09Rows`; the simulated curves are retained in `cell09Result.curves` in permutation-major order, with `cell09Rows.length` values per permutation.

The primary scan uses valid `rating` values from 1 through 5 and finite distances from 0 through 1,500 m. At every 25 m radius with at least 20 restaurants in each group it compares the cumulative inside mean with the outside mean. A fixed-seed set of 9,999 rating permutations produces the one-sided maximum-standardized-statistic global p-value and a simultaneous upper envelope. The 250 m comparison is descriptive when ineligible. To add an independent exploratory scan, set `cell09SensitivityMinimum` in the first cell to a smaller positive integer such as 9; this scan has its own maximum-statistic correction and can be unstable with small groups. `cell09Sensitivity` contains its full results.

The permutation test assumes ratings are exchangeable among restaurant locations; spatial dependence and differing restaurant characteristics can undermine that assumption. It tests an association rather than causation, and neither the first eligible radius nor the radius of the largest statistic identifies the edge of a proximity effect.
